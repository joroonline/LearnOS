# LearnOS

LearnOS is a minimal, fully documented Linux-based operating system designed to teach the internal workings of init, userspace, permissions, and more - by building everything yourself.

The goal is not to reinvent Linux, but to learn it deeply by gradually replacing all userland components with self-written tools, scripts, and eventually binaries.

---

## Goals

- [ ] Build the Filesystem
- [ ] Compile Kernel, Init, etc.
- [ ] Build a initramfs
- [ ] finish the boot into the system
- [ ] finsih the documentation

---

## Why?

- **Education**: Learn how Linux work - from zero to OS
- **Practical**: Build the tools, scripts and system by yourself
- **Modular**: Use existing parts (e.g. init) and replace them with other projects over time
- **Open**: Licenzed under GNU GPLv3 - controbutions welcome

> Learn OS - Learn by building the OS itself.
